봇 관리

역할마다 다른 봇 계정을 연결해 이름으로 역할을 구분합니다. 봇 하나가 여러 역할을 맡아도 됩니다.

먼저 확인하세요 — 본인 방송이나 허락받은 방송에서만 쓰세요. 봇 계정의 유튜브 이름에 역할이 드러나게 지으세요 (예: 히든 소통봇, 히든 안내봇). 봇마다 표기가 메시지 앞에 붙고, AI 리액션을 맡은 봇은 표기를 비울 수 없습니다. 한 역할은 한 봇만 맡을 수 있습니다.
처음이라면: Google Cloud 에서 OAuth 파일 만드는 법 (봇 계정마다 약 10분)
  1. 새 프로젝트 만들기 ↗
  2. YouTube Data API v3 ↗ 에서 사용
  3. OAuth 동의 화면 ↗ — 외부, 테스트 사용자에 봇 계정들 추가
  4. OAuth 클라이언트 만들기 ↗ — 데스크톱 앱 → JSON 다운로드

💡 할당량: 프로젝트마다 하루 10,000 단위입니다. 봇마다 프로젝트를 따로 만들면 각자 10,000, 같은 JSON 파일을 여러 봇에 쓰면 10,000을 함께 씁니다. 채팅 1건 전송 ≈ 50, 채팅 읽기 1회 ≈ 5 단위.
